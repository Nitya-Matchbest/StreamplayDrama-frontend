## 🐛 Troubleshooting

### **Cards not showing?**
- Refresh the page (Ctrl+R or Cmd+R)
- Clear browser cache
- Check if CSS files loaded

### **Animations not playing?**
- Scroll to section (animations on viewport entry)
- Check if browser supports CSS animations
- Disable "Reduce Motion" in OS settings

### **Hover not working?**
- Make sure you're on desktop (not mobile)
- Try different browser
- Check if CSS loaded properly

### **Layout broken?**
- Check browser width
- Refresh page
- Try different browser
